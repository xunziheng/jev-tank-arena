# 专家战斗控制验证（2026-09-22）

本轮是 Jev 战术 + 本地反射升级，不宣称无敌，也不提高 AI 生命、移速、弹速或赋予透视。

## 离线对比

运行 `npm run benchmark`：24 个固定角度、距离的单发来弹场景。对照为原地等待，实验组启用本地预测闪避。两组使用相同物理和来弹。

- 对照组累计损失生命：24
- 预测闪避组累计损失生命：0
- 反射介入：24 次
- 一次反弹射击搜索 + 八方向危险评估的本机样本：中位 0.61ms，P95 1.48ms（单次开发机测量，非浏览器帧率保证）

这是基本闪避能力的固定场景回归，不是对人类、规则 AI 或 Jev 的比赛胜率；不覆盖多弹包围、复杂地图、连续激光或所有弹道。

## 真实 API 快照验证

使用用户已配置的服务端密钥，未输出密钥。只调用 `/api/decision` 的相同处理函数，无常驻监听服务。两轮各 4 次请求，模型成功响应标识为 `jev-1.13.0`。

第一轮：

| 场景 | 结果 | 端到端时间 |
|---|---|---:|
| 直射窗口 | 1.5s 请求超时 | 1521ms |
| 迎面来弹 | maneuver_2，风险 0 | 1496ms |
| 激光预警 | maneuver_2，风险 0 | 1386ms |
| 道具争夺 | fire，风险 0 | 475ms |

根据结果去掉 criteria 与 state 中重复的候选描述，缩短提示词，将请求超时改为 2.5s、战术响应有效窗口改为 1.8s，并保留当前风险重验。第二轮：

| 场景 | 结果 | 端到端时间 |
|---|---|---:|
| 直射窗口 | 请求未成功（约超时上限） | 2529ms |
| 迎面来弹 | 请求未成功（约超时上限） | 2505ms |
| 激光预警 | maneuver_2，风险 0，置信度 0.89 | 367ms |
| 道具争夺 | maneuver_0，风险 0，置信度 0.29 | 465ms |

激光快照输入由 1781 tokens 降到 1117 tokens。不同请求的延迟不能据此推断为优化因果；网络/服务延迟仍有明显波动。总计 8 次尝试中 5 次成功，3 次失败。成功的低风险选择只能证明这些快照上的接口与选择成立，不能证明对战强度。

下一步由实际对局记录胜率、命中率、自伤次数、避险成功率和延迟分布。250ms 是目标最小调度间隔，不是已测稳定响应速度。
